# ERC-8257 tool discovery

## Locked inputs

- ERC-8257 specification: `ethereum/ERCs` commit
  `1b1b3f854f5c1b8b2b8380211d01db68e94dcf0d`.
- Reference implementation: `ProjectOpenSea/tool-registry` tag `v0.7.0`, commit
  `2ad79f4db6824cd81a1e5912f07a7b668225b34e`.
- Manifest validator: `@opensea/tool-sdk@0.7.0` used as a development-only CLI;
  it is not a runtime dependency.

The reference implementation passed its 290-test suite before deployment. Census does
not deploy an access predicate, payment module, or agent wallet. Every registration is
open access with `accessPredicate = address(0)`, and every manifest omits `pricing` and
`access`. ERC-8257 is discovery for report-only tools; it does not expand the v6 mint
contract and does not introduce x402 or transaction authority.

not be described as indexed or searchable through OpenSea until OpenSea adds Sepolia.

All seven onchain configs were read back after receipt. Their creator, URI, hash, and
zero predicate match this table, and `hasAccess` returns `true` for every ID.

The invocation route is `POST /tools/<slug>`. Its body contains `censusAddress`,
`tokenId`, and the skill-specific `input`. The runtime reads the live ERC-8217 binding,
requires the token's immutable skill to match the slug, applies the shared rate limit,
and returns a report without submitting a transaction.
